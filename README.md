# Negosud Web

Second version of the Negosud front-end, a management app for a wine merchant.

## Features

- Authentication and user profiles
- Products and orders (commandes) pages
- Shared layouts and navigation
- Cypress end-to-end tests

## Tech Stack

- Vue 3, Vue Router, Pinia
- Vite
- Cypress

## Getting Started

```bash
git clone https://github.com/ghostland-dev/negosud-frontend-v2.git
cd negosud-frontend-v2
npm install
npm run dev
```
